# Purpose

- Compile HTML/CSS and HyperFrames compositions into Director scenes without browser frame rendering.

## Ownership

- `src/` owns parsing, cascade, style translation, deterministic animation, native element adapters, and captured-scene loading.
- `src/property.rs` owns the property table: every compiled longhand, whether it inherits, and its translation group. `css::inherited` and the unsupported-property refusal read it. `src/computed.rs` owns `ComputedStyle`: the text map plus a typed Lightning CSS `Property` per longhand, reached through `computed(name)`. It derefs to the text map for text-path readers.
- `src/style/mod.rs` owns `translate`, group dispatch and the text-path properties: color, font-size, font-family, font-variant-numeric, gaps, grid templates and placements, background-image and the background-position shorthand, mask-image, transform and perspective origins, line clamps, decoration lines and thickness, underline offset, text stroke, paint-order, object-fit and object-position, clip-path, animation and transition. Typed group modules: `style/layout.rs`, `style/background.rs`, `style/border.rs`, `style/boxes.rs` (opacity, visibility, overflow, z-index), `style/effects.rs` (box shadows, filters, backdrop blur, blending, mask mode), `style/transform.rs` and `style/text.rs`. A group module returns `None` for names it leaves to the text path.
- `src/element/mod.rs` owns `HtmlElement`, its layout hooks, and the paint order: transform, clip path, effect layer, outer shadows, background, inset shadows, content and children, borders, mask. `src/element/background.rs` owns box shadows, background colors and layers, and `background-clip: text`. `src/element/borders.rs` owns border sides, styles, and corner joins. `src/element/text.rs` owns text decoration lines.
- `src/beats.rs` owns the composition's beat grid and beat-time parsing (see Beat grid). `director_core::beats` detects grids from audio.
- `src/reel.rs` owns slot-reel expansion (see Slot reels).
- `src/timeline.rs` owns `director-timeline/1`: the serde document, its validation and collection from the page. `animation::from_track` turns one track into a native `Animation`.
- `src/gsap/mod.rs` owns page-script execution: it loads the scripts, runs them in Boa against the DOM in `src/gsap/dom.rs` and the browser globals in `src/gsap/dom.js`, seeks every frame, and turns the recorded changes into baked HTML and `director-timeline/1` tracks. `compiler::probe` answers its layout reads. `src/gsap/ease.rs` owns the GSAP ease names and curves. `animation::Parts` owns the transform component channels.
- `src/project.rs` owns `director-native-project/1`, editable source and validated element overrides; `src/assets.rs` owns asset recording, deduplicated SHA-256 blobs and temporary media-file leases.
- `tools/` owns optional compile-time browser extraction, Chromium and CPU/GPU parity, real HyperFrames CLI and CPU/GPU export benchmarks, and Hyper CN registry auditing.
- `tests/` owns executable compatibility and pixel regressions.
- `benches/` owns Criterion compile/render workloads.
- `README.md` owns the user-facing feature summary, incompatibilities, commands, and reproducible measured results. This file owns the exact behavior contracts. Current phase status and test counts live in `docs/plans/10-native-platform-overhaul.md`.

## Local Contracts

### Architecture

- Depend on `director-core`; do not introduce HTML behavior into Rhai or the core dependency-graph compiler.
- Use upstream HTML, CSS, selector, layout, typography and SVG libraries. Unsupported syntax or rendering behavior must produce diagnostics; compilation fails when errors remain.
- Native adapters must remain semantically Send under the core scene-node contract. Share captured graphs behind `Arc<Mutex<SceneGraph>>`, never `Rc` or an unprotected shared graph.
- A capture's `Element::sampled_graph` returns the locked graph and root of the active sample, and `director-render` paints it with a fresh static cache. `CapturedElement::render` paints nothing itself.
- Generated captures, videos, reference checkouts and benchmark reports live under ignored `target/` or user-selected outputs.

### Native projects

- Native projects preserve HTML/capture authoring data and compile it on load. Do not serialize HTML adapters through core project I/O, which owns a different node-kind contract.
- Pack every consumed local stylesheet, font, image, audio and video plus required bundled fonts. Frozen project compilation cannot read original files or substitute host files for missing blobs; hash mismatches fail.
- Apply edits by stable authored element ID and validate the complete candidate before acceptance or atomic save. Captures retain sampled timing and fixed geometry; reject edits requiring uncaptured layout/animation.
- Preserve unique authored capture IDs. Anonymous/duplicate IDs receive noncolliding structural paths, stable while sampled topology is stable; expose those paths in inspection and store them in packed captures.
- Keep extracted media files alive through the Director asset-loader lifetime, even when the project or compiler wrapper is dropped.
- Share immutable source and encoded blobs across edit candidates; validation must not clone entire media payloads merely to change an edit map.

### Capture and extraction

- Browser extraction is explicit and compile-time only. Capture layout, style, SVG and media references, never screenshots as native scene content. Captures declare their sample rate and cannot claim continuous animation equivalence.
- The capture format is `director-html-capture/1` with `deny_unknown_fields`. New fields must be optional with defaults.
- Registry audits must distinguish renderable inputs from diagnosed incompatibilities.
- The extractor forwards a non-none computed `perspective` with its origin, `backface-visibility: hidden`, SVG-descendant `filter` and `mix-blend-mode`, `transform-style: preserve-3d` (flat is omitted, so a captured flat parent stays flat), `text-decoration-line` when every token is `underline`, `overline`, or `line-through`, `mask-mode: luminance`, `position` when it is `fixed` or `sticky` (geometry stays the sampled rect), `font-variant-numeric`, `text-indent`, the `-webkit-text-stroke` properties, `overflow-wrap`, and `word-break`. These forwards have node tests and have not been re-smoked in Chrome.
- The extractor refuses other decoration values, mask modes other than alpha, match-source, and luminance, `background-blend-mode`, image-url backgrounds, generated content, and iframe.
- Captured SVG markup rejects `foreignObject`, SMIL, scripts, and nested images.
- Captured style edits accept only the previous paint list. Perspective, transform, and border-style edits on a capture fail. Authored HTML recompiles them.

### Paper Shader translation

- Do not treat Hyper CN WebGL/canvas content as supported until a native translation exists. A canvas with a captured Paper Shader fragment compiles to SKSL and draws in the element content rect. A canvas with no fragment stays refused, as do other WebGL and Three.js runtimes. The translator never inserts a screenshot.
- The capture stores the fragment and the uniforms uploaded for that sample. GLSL ES 300 becomes SKSL at compile time, so a translator fix does not require a new capture.
- Object-like `#define` expands; a function-like `#define` is an error. `uniform bool` becomes `uniform int`. Precision qualifiers are stripped.
- `fwidth`, `dFdx`, and `dFdy` become a constant of about `1.5 / max(resolution)`. `textureGrad` drops the explicit derivatives. `textureSize` uses the captured image's pixel size, and a sampler-typed function parameter is replaced by the captured image name.
- `round` and `float2x2` transpose use helpers. Integer `%` truncates toward zero and a zero divisor returns 0. Integer `clamp` uses `paperClampInt`. A rising `for` loop bounded by that clamped int runs to the clamp's literal max and breaks once the index passes the live bound.
- `samplerCube`, `sampler3D`, integer samplers, `texelFetch`, image load/store, and barriers stay refused.
- `u_time` is the seek time in seconds times the authored mount speed.

### Captured media

- Captured muted video shares one decoder per element id. Sample rect and `object-fit` may change. The active sample seeks that decoder to the composition time. Muted `video loop` seeks with `media_start + elapsed * playback_rate`, then wraps into `[0, duration)` using the ffprobe duration. The extractor records `looped`.
- Captured audio is one mixer track per id, including an element the visibility window hides. `data-hidden` sets track volume 0. Audio `loop` loops the track. `data-media-start` drains samples the same way as static HTML. Bytes come from the capture asset map.
- Unmuted video, an audio playback rate other than 1, iframe, a duplicate media id in one frame, and a media id whose src or timing changes across samples fail. DOM paint stays on the held sample.

### Cascade and at-rules

- Nested style rules flatten into the same selector list as top-level rules. `&` is replaced with the parent selector. A parent list becomes `:is(...)`.
- Nested `@media` and `@supports` evaluate at compile time against the composition size. `(orientation: landscape)` is true when width is at least height. `(aspect-ratio)`, `(min-aspect-ratio)`, and `(max-aspect-ratio)` compare width/height to the ratio. Top-level `@media` fails with `unsupported CSS at-rule`. Unknown media features fail.
- The cascade carries each winning declaration's parsed `Property` into `ComputedStyle` with no reparse. Only a value containing `var()` is substituted as text and parsed again. `inherit` copies the parent's text and typed value. Custom properties keep text only.
- Lightning CSS 1.0.0-alpha.72 leaves `transform-style: preserve-3d`, `text-shadow: none` and `box-shadow: none` unparsed. The typed modules match those three texts explicitly.
- `@supports` is true for `display` (`block`, `flex`, `grid`, `inline`, `inline-block`, `none`), `background-clip` (`text`, `border-box`, `padding-box`, `content-box`), `text-overflow` (`ellipsis`, `clip`), `object-fit` (`fill`, `cover`, `contain`, `none`, `scale-down`), `position` (`static`, `relative`, `absolute`, `fixed`, `sticky`), and `overflow` / `overflow-x` / `overflow-y` (`visible`, `hidden`, `clip`). Any other declaration fails.

### Layout

- `display`, `box-sizing`, `position`, sizes, insets, margins, paddings, `flex-direction`, `flex-wrap`, `flex-grow`, `flex-shrink`, `flex-basis`, the `align-*` and `justify-*` properties, `aspect-ratio`, and `grid-auto-flow` translate from typed values in `style/layout.rs`. Grid templates, grid placements, and gaps stay on the text path.
- `display` accepts `block`, `flex`, `inline-flex`, `grid`, `inline-grid`, and `none`; `inline` and `inline-block` ask for a rich text parent. Alignment accepts `normal`, `stretch`, `start`, `end`, `flex-start`, `flex-end`, `center`, and first `baseline`; content alignment adds the `space-*` values. Overflow keywords, `left`, `right`, `self-*`, and `last baseline` fail. Sizes other than `auto`, `none` for maxima, and a length fail.
- Homogeneous `calc()`, `min()`, `max()`, and `clamp()` lengths become px. Homogeneous percents stay percents (`50%` is fraction `0.5`). `convert_length` passes no percent basis. `length_on` resolves a mixed calc when the caller supplies a finite basis greater than 0.
- Mixed-calc bases: width, min-width, max-width, left, right, margin, padding, text-indent, and a length flex-basis use the containing-block width. Height, min-height, max-height, top, and bottom use the containing-block height. Padding and margin use width on every side. column-gap uses the element's own definite content width; row-gap uses its own definite content height.
- The root containing block is the composition size. A nested box uses its parent's definite content box. An auto block width stretches to that box. An auto height, an auto shrink-to-fit width, and a grid item with width auto stay indefinite. A missing, zero, negative, or non-finite basis fails with `mixed calc() requires a length basis`.
- A gradient color stop written as `calc(<percent> + <px>)` or `calc(<px> + <percent>)` uses the gradient line length; a radial stop uses the ending radius. `calc(50% + 10px + 1em)` fails on a gradient stop. A zero-length gradient line keeps the mixed-calc error. `round`, `rem`, `mod`, `abs`, `sign`, and `hypot` fail.
- `grid-template-columns` and `grid-template-rows` accept an integer `repeat` up to 4096, `repeat(auto-fit, ...)`, `repeat(auto-fill, ...)`, `[line]` names, and `subgrid`. An auto repeat nested inside another repeat fails.
- `subgrid` copies the parent axis when that axis has a known track count, including its line names. A grandchild line name places on that copied line. `subgrid [name]` adds those names when one group is present for every parent line. A missing parent axis, an auto-fit or auto-fill parent, a name list of a different length, and `subgrid` inside `repeat()` fail.
- `grid-column` and `grid-row` accept `auto`, a line number, `span N`, or a line name stored on the parent template. A length glued to `[name]`, the form lightningcss emits, is that track plus the name. A missing name or a bare custom ident fails with `named grid lines`.
- An absolute or fixed child of a text block sits beside the block's anonymous text leaf, and an atomic `inline-block` may hold text plus absolute children. A positioned box inside an inline box fails with `a positioned box inside an inline box requires extraction`.
- `position: fixed` is out of flow and uses the composition as its containing block. A transformed ancestor does not recapture fixed. `position: sticky` stays in flow, stretches like a static block, and its insets stay auto. There is no scroll offset.
- `line-clamp` and `-webkit-line-clamp` accept `none` or a positive integer and ellipsize at that line count inside the content width. `text-overflow: ellipsis` requires `white-space: nowrap` and overflow-x hidden or clip. Visible nowrap spills.

### Backgrounds, borders, masks, and filters

- Repeating gradients compile to the same linear, radial, or conic shader as the non-repeating form. Stops expand across the unit interval by the first-to-last period, then clamp. A period under `1e-4`, or fewer than two surviving stops, paints the last color. Expansion stops at 240 cycles and 720 stops. Equal positions with different colors are nudged by `1e-4` so the hard edge survives.
- Color hints expand in sRGB before tiling. A hint must sit strictly between two color stops. A hint on the left stop becomes the next color; a hint on the right stop becomes the previous color. A 50% hint is dropped. Any other hint inserts nine sRGB stops on the Gecko midpoint curve. Vendor-prefixed gradients and orphan hints fail. A hint that parses and then fails expansion paints nothing.
- A gradient shader is sized to `background-origin` and clamped across the border box. The default origin is padding-box, so a transparent border shows the end color. Radial and conic centers include the origin rect's top-left. Masks stay on the border box. A length `background-size` tiles a gradient when an axis repeats. `tiled_gradient` records the gradient once at the tile size and repeats that picture in 2D, so a radial dot stays a dot; a `no-repeat` axis decals. `to bottom right` uses the CSS corner angle of the painted rect; a square is 135deg.
- Any number of `url()` or `data:` layers may share `background-image` with gradients. CSS order paints the first layer on top. A file URL resolves through the compile `AssetStore`, so `CompileOptions.base_dir` and frozen project blobs apply. A data URI decodes inline. A missing file fails. `none` layers are dropped before list indexing.
- `background-size`, `background-position`, and `background-repeat` are comma lists aligned with the layers. A shorter list cycles by source index, and the x and y lists cycle independently. Size accepts `auto`, `cover`, `contain`, and lengths. `background-position` takes one or two values per layer; one value sets x and centers y unless it is `top` or `bottom`. Three or four values fail.
- `repeat`, `no-repeat`, `repeat-x`, and `repeat-y` use the image shader. `space` and `round` paint explicit tiles, including mixed with a repeat axis, capped at 4096 tiles.
- `background-origin: content-box` insets by the border plus padding; percentage padding uses the element width. `background-clip` `content-box` clips to the content edge, `padding-box` to the padding edge, and `border-box` paints the border box. A per-layer origin or clip list whose layers all agree acts as that one value; a mixed list fails. Fixed or local attachment fails.
- A uniform dashed or dotted border (same line, width, and color on every side) strokes one inset rounded rect. Mixed side styles clip to the border ring, fill solid sides with center-meeting wedges, and stroke dashed or dotted sides along their midlines. Dashes are `3w` on and `3w` off. Dots are a zero-length dash with a `2w` gap and a round cap. Gaps show the element background.
- Border styles also accept `double`, `groove`, `ridge`, `inset`, and `outset`. `hidden` zeroes the used width. `wavy` fails.
- `mask-mode: luminance` writes Rec.709 luma into alpha and blends with `DstIn`. A non-gradient mask image fails.
- `clip-path` accepts `polygon()`, `circle()`, `ellipse()`, and `inset()` without `round`. `url()` fails.
- `filter` accepts `invert`, `sepia`, and `opacity` after the existing color matrix, clamped to `0..=1`.
- An empty filter call takes the CSS default amount: `blur()` and `hue-rotate()` are no-ops, and `brightness()`, `contrast()`, `saturate()` and `grayscale()` take 1. `tests/filter_fns.rs` covers a chain of default amounts.
- `object-fit` accepts `fill`, `cover`, `contain`, `none`, and `scale-down`; the core `ObjectFit` default stays `Cover`. `object-position` positions image and video content, including a captured video's shared decoder. The default is 50% 50%. Keyword order can swap axes. One keyword plus a length sets the other axis.

### Text

- `text-decoration` paints `underline`, `overline`, and `line-through`. Styles are solid, double, dotted, dashed, and wavy. `text-decoration-color` paints that color; `currentcolor` stays the text color. Thickness is `auto`, a length, or a percent of 1em. `from-font` uses the font underline thickness and falls back to auto when that metric is missing or not positive. `text-underline-offset` shifts only the underline; `auto` and `0` leave it, and a percent is a fraction of 1em.
- `text-transform` accepts `none`, `uppercase`, `lowercase`, and `capitalize`. `capitalize` uppercases the first character of each whitespace-separated word. `full-width` and `full-size-kana` fail.
- `text-shadow` paints a list of shadows in CSS order, the first on top; `none` paints none. A non-zero spread fails.
- `overflow-wrap` and `word-wrap` accept `normal`, `break-word`, and `anywhere`; `break-spaces` fails. `word-spacing` adds px after each space and tab; `word-break` accepts `normal`, `break-word`, and `break-all`; `keep-all` fails. `anywhere`, `break-word`, and `word-break: break-word` break a token that does not fit. `break-all` also splits a token that overflows the space left on the line. `normal` keeps that token on one line, and left alignment lays the line out past the box. Soft min-content stays the unwrapped line, so `anywhere` does not shrink to one character.
- Text in a box sized to its own text stays on one line. Taffy rounds box edges to whole pixels, so such a box can come out up to a pixel narrower than its line, and Skia also breaks a line laid out at exactly its own width. `layout_paragraph` gives a line `WRAP_SLACK` (1 px) past its box before the next word wraps, lays out a line within a pixel of its box a pixel wider than itself, and the element keeps the paragraph's alignment edge, so centred text stays centred. `append_wrapped` adds up unkerned token widths, which run several pixels past the shaped line at display sizes, so `wrap_width` skips that pre-wrap when the shaped lines already fit. A centred or right paragraph measured at max-content lays out again at its own width, because Skia reports no lines for it at an infinite width. `tests/shrink_wrap.rs` covers each alignment at four sub-pixel offsets, with kerned text up to 72 px.
- `visibility: hidden` on an inline span keeps its advance and paints no fill, stroke or shadow. `TextSpan::hidden` carries it, and the scene document stores it.
- `white-space: pre-line` keeps hard breaks and collapses spaces. `pre-wrap` preserves spaces and wraps.
- `<br>` is a hard break under every `white-space` mode. A collapsible space beside it is dropped, and a trailing `<br>` adds no line. An inline child (`span`, `b`, `strong`, `em`, `i`, `small`) of a text block may set inherited and `font-*` properties. It ignores `box-sizing` and zero margins and paddings, which a `*` reset gives every span. `position: static` and `relative` are inert on it. Any other property on it fails with `styled inline boxes require extraction`. An inline child with `display: none` takes no space. `tests/rich_text.rs` covers these.
- Atomic inline boxes: an `inline-block` child, and an inline child that GSAP or a timeline animates, compile as scene boxes placed on the text lines. The text moves into an anonymous leaf, the first child of the block, with one U+FFFC per atomic. Its paragraph reserves a Skia placeholder of the atomic's margin box, and a placeholder that overflows the line wraps to the next one. The atomic box becomes `position: absolute` with its compile-time border-box size (max-content text plus padding and border, or its own length size). The leaf's `post_layout` stores each placeholder rect in a shared `InlineFlow`, and the box's `Element::layout_origin` returns that slot plus its margin. An animated atomic box resizes every frame: its `update` measures its live text, padding, border and margin, sets its border box and publishes its margin box in the `InlineFlow` (an `auto` axis follows the text, a `content-box` length adds the live edges). The leaf's `Element::pre_layout` rebuilds its paragraph when a published box changes and relayouts, so the line reflows around a growing span. `AtomicSizing` records the author's auto axes and box sizing, and the scene document stores them on `InlineFlow::Box`. An atomic box drops relative insets. An inline-block with in-flow block children fails with `inline-block with block children requires extraction`, and a text track on a block with atomics fails.
- `font-variant-numeric: tabular-nums` sets `tnum`. `text-indent` inserts a leading placeholder; `hanging` and `each-line` fail. `-webkit-text-stroke` paints one stroke; width `0` skips it. A stroke colour that differs from an opaque fill paints from its own paragraph, ordered by `paint-order`. `paint-order` takes `normal` or `fill`, `stroke`, and `markers` once each in any order; unlisted layers follow in the order fill, stroke, markers. `normal` paints the stroke over the fill, and `stroke fill` paints it under. A repeated or unknown layer fails. Neither property inherits, so set both on the element that holds the text.
- The `font` shorthand compiles. `font-variant-caps` accepts only `normal`; any other value fails. `font-stretch` keywords and percentages and `font-variation-settings` (quoted four-letter axis tags with numbers) inherit and become variable font axis positions on the text spans: `font-stretch` sets `wdth` unless `font-variation-settings` names it. Fonts without an axis ignore it. `tests/font_shorthand.rs` covers the shorthand and stretch values.

### Transforms and 3D

- Both transform paths wrap rotate and skew angles into `[0, 360)` before asking lightningcss for a matrix. lightningcss builds no matrix for a negative angle or a full turn and above, and a list without a matrix paints untransformed. `tests/transform_angles.rs` covers negative rotate, rotate past a turn, and negative skew.
- A transform list that contains a projective function resolves lengths to pixels and uses the lightningcss matrix. A 2D result stays on the affine canvas matrix. A 3D result is the column-vector matrix in row-major order with translation in the fourth column. Non-projective lists keep the 2D path.
- `perspective` projects descendants only. It wraps descendant drawing as `translate(origin) * perspective(distance) * translate(-origin)`; the element's own text, image, and SVG draw before that wrap. The default origin is `50% 50%`. Distance and `translateZ` must be absolute px. An absolute `transform-origin` z pivots the local matrix. A percent z and `perspective-origin` z fail.
- `transform-style: preserve-3d` depth-sorts by ascending Z of each child's center after its own local matrix, then z-index, then source order. A direct child that also preserves 3d contributes its descendants, and depth sums along that chain. A non-sharing child stays one plane. An affine child has Z 0. The depth key excludes the parent perspective. A plane whose Z changes across its quad, such as crossing `rotateX` cards, is occluded per pixel; constant Z stays on the center sort. `flat` keeps z-index order. Other values fail.
- `backface-visibility: hidden` skips an element whose own matrix `m33` is negative. The cleared frame is opaque black, so a hidden backface reads as `[0, 0, 0, 255]`.
- CSS animation identity and interpolation cover `rotateX`, `rotateY`, `rotateZ`, `translateZ`, `translate3d`, and `perspective`. The identity perspective distance is `1e6` px. Animated lengths on those functions must already be px.

### SVG

- An external stylesheet may set `fill`, `fill-opacity`, `fill-rule`, `color`, `stroke`, `stroke-width`, `stroke-linecap`, `stroke-linejoin`, `stroke-dasharray`, `stroke-dashoffset`, `stroke-opacity`, `stroke-miterlimit`, `opacity`, `transform`, `clip-path`, `clip-rule`, `filter`, `mix-blend-mode`, `marker-start`, `marker-mid`, `marker-end`, `mask`, `font-family`, `font-size`, `font-weight`, and `font-style` on SVG descendants. Each declaration is appended to the element's `style` attribute. `transform` values drop `px` because usvg rejects them. `clip-path` and the marker longhands are copied as printed. The `mask` shorthand is stored as `mask-image` and written back as `mask`; HTML `mask-image` stays on the HTML mask path. External `animation` and its longhands fail.
- An internal `<style>` inside the SVG stays in the markup and is not added to the document CSS.
- SVG `<text>` is shaped with the bundled Roboto, Inter, and Poppins faces plus document `@font-face` faces. The default family is Roboto and the default size is 16. The font database loads on the first SVG. Rhai `VectorNode::new` still parses with an empty font database.
- resvg clamps each isolated group layer (clip-path, mask, opacity, filter) to `-2 * size .. 3 * size` of its target in the parent layer's coordinates, so paint reaching far left or above the viewBox through three or more nested layers vanished. `VectorNode` pads the raster left and top past every layer's reach, up to twice the output size per side, and crops back. `node/vector.rs` tests cover left reach, top reach, and the unpadded case.
- An authored `foreignObject` lays out its HTML children in that viewport and paints them after the SVG raster. `x`, `y`, `width`, and `height` accept a number, `px`, or a percent of the SVG viewport, and user units map through `viewBox`. The box clips overflow. A non-positive width or height paints nothing. Loose text fails with `foreignObject text requires an HTML element`. A transform on the `foreignObject` or an SVG ancestor fails with `transformed foreignObject requires extraction`. A nested `foreignObject`, or one inside a nested `svg`, `symbol`, `defs`, `marker`, `pattern`, `clipPath`, or `mask`, requires extraction.
- Authored SMIL: `animate`, `animateTransform`, `animateMotion`, and `set` are sampled at the element's local time, patched into the markup, stripped, and reparsed. One animation per attribute. `animate` and `animateTransform` interpolate numbers or colors linearly. Text values with the same numbers in the same places, such as two `matrix()` lists or two path strings, interpolate number by number. `director-clock="composition"` on an animation reads `begin` and `dur` in composition seconds and maps them through the clip start, `data-media-start` and `data-playback-rate`. `animateMotion` follows a paced polyline and appends a translate. `set` holds `to`. `fill` is `freeze` or `remove`. The layout box stays the time-0 SVG size. Spline timing, `keySplines`, `keyPoints`, `mpath`, begin or end lists, `additive` other than replace, `accumulate` other than none, `min`, `max`, motion `rotate` auto, path curves, and unknown SMIL attributes require extraction. The animated SVG marks the element as time-varying for the static cache.
- Scripts and nested images fail with `SVG scripts and nested images require native translation`.

### Scene document

- Every native adapter has a document body. `src/export.rs` writes `HtmlElement` as `NodeBody::Html` from `base_style` and `base_paint`, so an export after rendering records the unanimated box. Its opacity channel is the base paint opacity. Text content uses `nodes::text_export`, because the stroke paragraph rebuilds from the paint.
- Gradients, CSS animations, Paper shaders and SMIL animations convert in their own modules through `to_doc`. `PaintStyle::filters` keeps the typed filter list beside the compiled `filter` chain, and both change together.
- Background images and inline SVG markup embed as assets. Paper shader images embed as raw RGBA8 (`application/x-rgba8`).
- Native and captured videos have kind `html_video` and export `HtmlVideoBody` with their loop flag and duration. A non-looped native video exports the core video body. A capture exports each distinct sampled graph once through `export_graph`, with a per-sample index list.
- Fonts registered from HTML stay outside the document, matching core text.
- Audio and video with a file `src` export as a path asset holding that `src`, which the compile `AssetStore` resolves against `base_dir` or frozen blobs. Captured media record their packed asset reference the same way. Audio `data-media-start` becomes the track `source_start`; video keeps it on the HTML body. A data URI `src` embeds the decoded audio samples or the video file bytes.
- `tests/scene_document.rs` round-trips every `examples/html` file, a paint fixture, SMIL, a looped video with a path asset, file and data URI audio, a two-graph capture and a Paper shader through JSON.
- `src/import.rs` is the inverse for the HTML kinds: `register_import(&mut registry)` adds the `html`, `html_video`, `html_capture` and `svg_smil` decoders. The `html` decoder rebuilds `PaintStyle` (the compiled `filter` chain from `filters`, the transform from its CSS text), decodes the content body through the registry, rebuilds text content with `compiler::prepare_paragraph`, relinks `HtmlBody::inline` flows through `ImportContext::shared` under `html-inline-flow-{id}`, and restores animations and the Paper shader through each module's `from_doc`. Video content of a box goes through `capture::decode_box_video`, so boxes with equal video and timing share one decoder through `ImportContext::shared`, matching the sharing between capture samples.
- `capture::decode_capture` imports each sampled graph through `scene_import::import_graph`, restores every node's sampled rect from `CaptureGraph::rects` and calls `post_layout` with it, and keeps equal samples on one shared graph. `smil::decode` rebuilds `AnimatedSvg` from its markup asset and animations, resolving SVG text against the bundled faces (`compiler::bundled_svg_fonts`) plus the document's font faces.
- `AssetStore` implements `AssetLoader::media_path`, so imported path-asset video decodes from the project file.

### Beat grid

- The composition root sets a fixed grid with `data-bpm` and `data-beat-offset` (seconds of position 0), or a music track sets it: the `audio` element with `data-timeline-role="music"`, else the first whose id contains `music`, `bgm` or `soundtrack`. `data-bpm` alone with a music track fixes the detected tempo; alone without one it starts the grid at 0 s. `data-beats-per-bar` (whole, 1 to 32) defaults to 4. The track's `data-start` minus `data-media-start` shifts its beats onto the composition clock. These three attributes on any other element fail with `belongs on the composition root`, and `data-beat-offset` without `data-bpm` fails.
- The grid resolves on first use, so a page that names no beat never decodes its music; the decoded samples then feed the music's own audio track. `CompiledHtml::beat_grid` holds the resolved grid and `beat_grid_file` resolves a page's grid without compiling it.
- A beat time is terms joined by `+` or `-` with an optional leading minus: `<n>b`, `<n>beat`, `<n>beats`, `<n>bar`, `<n>bars` and `drop`. Position 0 is the first downbeat. Text that names no beat unit stays seconds. `data-start`, `data-end`, the root's `data-duration` and timeline JSON keyframe `time` strings take beat times as grid points; a clip's `data-duration` counts beats and bars from its start and refuses `drop`. A beat time with no grid, a grid with no drop, and a malformed term fail.
- GSAP scripts read the grid through `director.beat(position)` and `director.bar(n)` (seconds), `director.position(seconds)`, `director.bpm`, `director.beatsPerBar` and `director.drop` (a position, failing when the music has none).
- `data-sfx` on a clip plays its file once from the clip's start on the composition clock, at `data-sfx-volume` (default 1), silent when the clip or an ancestor is `data-hidden`. A sound effect inside a `time` track fails.
- `tests/beats.rs` covers clip windows and the root duration on beats and bars, seconds without a grid, timeline keyframes, the GSAP API, a synthesized music track setting the grid and drop, sound effects and refusals. `examples/html/kinetic-beats.html` cuts words on bars, kicks a ring on every beat and fires a sound on the end card.

### Slot reels

- `data-reel` (no value) on a text-only element rolls each ASCII digit of its text through a clipped window to that digit; other characters stay static. `data-reel-from` gives the starting digits, right-aligned to the rolling digits (missing ones start at 0, default all 0). `data-reel-spins` (whole, 0 to 20, default 1) adds full turns, `data-reel-direction` is `up` (default) or `down`, and `data-reel-ease` (default `power3.out`) eases the landing.
- `data-reel-start` defaults to the clip start. Seconds add to the clip start, which counts a seconds `data-start` from the enclosing composition's start; beat times are absolute. `data-reel-duration` (default 1.2 s) and `data-reel-stagger` (default 0.1 s) take seconds or beat spans. Digit `i` lands at start plus duration plus `i` times stagger, left to right.
- The expansion runs before page scripts. Each digit becomes an `inline-block` window with `overflow: hidden` holding the final digit as `visibility: hidden` text, which sizes the window, beside an absolute strip of `display: block` digit cells with id `{id}-reel-{i}` (`reel-{n}-reel-{i}` without an id). A generated `director-timeline/1` script moves each strip on `translate-y-percent`, so `director-engine html timeline` prints the tracks and export and motion blur treat them as timeline tracks. The `data-reel*` attributes are removed.
- A value on `data-reel`, element children, text without ASCII digits or with other numerals, a `data-reel-from` longer than the rolling digits, a negative start, a non-positive duration, a negative stagger, out-of-range spins, an unknown direction, a beat time with no grid and a strip id already in use fail.
- `tests/reel.rs` covers rolling, start digits, direction and beat times, clip-relative seconds, positioned boxes beside text, hidden spans and refusals. `examples/html/kinetic-counters.html` rolls a revenue and a growth counter under an edge fade mask with motion blur.

### Timeline JSON

- `<script type="application/director-timeline+json">` carries a `director-timeline/1` document: `{format, tracks: [{target, property, keyframes: [{time, value, ease?}]}]}`. Unknown fields fail. Several timeline scripts merge into one timeline.
- `target` is an HTML `id`, or a structural path below the composition root: `/` for the root, `/i/j` with zero-based element child indices. `time` is seconds on the composition clock, or a beat time string (see Beat grid). `value` is CSS text, or a number: unitless for `opacity`, px for `width`, `height`, `left`, `top`, `border-top-left-radius`, `border-<side>-width`, `font-size`, `letter-spacing`, `word-spacing`, `padding-<side>` and `margin-<side>`, and a multiple of the font size for `line-height`. Color, `border-<side>-color` and transform tracks take CSS text. Border width, padding and margin tracks change layout.
- Filter channels drive one function of the element's `filter` each: `filter-blur`, `filter-drop-shadow-x`, `filter-drop-shadow-y` and `filter-drop-shadow-blur` in px, `filter-hue-rotate` in degrees, `filter-brightness`, `filter-contrast`, `filter-saturate`, `filter-grayscale`, `filter-invert`, `filter-sepia` and `filter-opacity` as factors, and `filter-drop-shadow-color` as CSS text. A channel writes its function in the cascaded filter list in place, else appends it, and the element recompiles its filter chain each frame. Zero blur and zero hue rotation leave the cascaded list, so their channels append.
- Shadow and clip channels drive one field of a list entry each: `box-shadow-<i>-x`, `-y`, `-blur` (the CSS blur radius) and `-spread` in px, `box-shadow-<i>-color` as CSS text, `box-shadow-<i>-inset` on at 0.5, and `clip-path-<i>-x` and `-y` as percents of the border box for corner `i` of the clip polygon (circles and ellipses have 24 corners, insets 4). A missing shadow (transparent, zero sized) or corner (at the origin) extends its list. Indices stop at 32 shadows and 256 corners.
- Text shadow and background position channels work the same way: `text-shadow-<i>-x`, `-y` and `-blur` in px with `text-shadow-<i>-color` as CSS text, and `background-position-<i>-x` and `-y` in px with `-x-percent` and `-y-percent` in percent for layer `i`. A missing text shadow (transparent, zero sized) extends its list, and a missing position layer extends the list by cycling the cascaded layers. Indices stop at 32.
- Background size channels `background-size-<i>-width` and `-height` take px, and `-width-percent` and `-height-percent` take percent. A keyword or `auto` layer turns into lengths with its other axis `auto`, and a missing layer extends the list by cycling.
- `font-size`, `letter-spacing`, `word-spacing`, `font-stretch`, `font-variation-<axis>` and `line-height` tracks rebuild the element's text spans each frame and relayout. Spans at the element's own size, spacings, axes or line height take the animated value; spans that set their own keep it. Other `em` lengths stay at the cascaded size. When the text sits in an anonymous leaf (a flex or grid box, or text beside atomic inline boxes), the leaf carries the element's inherited channels and `text` channel.
- Descendants inherit `color`, `font-size`, `letter-spacing`, `word-spacing`, `font-stretch`, `font-variation-<axis>`, `line-height` and `text-shadow` channels from every ancestor, ancestor channels first. A local property stops its channel (`font-variation-settings` stops every axis channel); a local relative font size (`em`, `%`, `larger`, `smaller`) scales the ancestor's font size channel instead. `img`, `svg`, `video` and `audio` inherit nothing.
- `ease` takes a CSS timing function and shapes the segment arriving at its keyframe; it defaults to `linear`. A track holds its first value before its first keyframe and its last value after its last one. A single keyframe holds for the whole timeline.
- A `time` track sets the clock of the target's descendants: each keyframe maps a composition second to a descendant second (a number, or `s`/`ms` text), and `ease` shapes the segment arriving at it. Before the first keyframe and after the last the clock runs at speed 1, so keys from 20 s to 0 s rewind the subtree and then replay it, equal values freeze it and steeper slopes ramp its speed. Descendant tracks, `@keyframes`, clip starts and ends, SMIL and video media time all read the remapped clock; the target's own paint, animations and visibility stay on the composition clock, so a rewind look (filters, shakes) animates on the target while its content runs back. The clock is a `TimeMap` on `HtmlElement` (`Element::child_time`), and the scene document stores it as `HtmlBody::time_map`. A time track on an element with its own text or replaced content, a text animation passing through it, a `position: fixed` descendant and an `audio` descendant fail. Rewound video seeks its decoder backwards every frame.
- A `text` track replaces the element's text with each keyframe's value and holds it until the next one. The element's own text shows before the first keyframe. An element with no text takes a text track. The scene document stores the values as `CssValue::Text`.
- Each track compiles to a native `Animation` (delay = first time, fill `both`) that exports and edits as a `CssAnimation`. Tracks apply before the element's `@keyframes`, so a running CSS animation of the same property wins, as it does over inline styles. A keyframed whole `transform` replaces the track's transform components while it runs.
- Refusals: another format, a duplicate target and property, an empty track, negative or non-finite times, times that do not increase, an unsupported property, a number on a color or transform track, and a target with no animatable element.
- `tests/timeline.rs` covers holds, easing, numeric values, color interpolation, scene export, serde round trips, tracks beside `@keyframes` and refusals. `tests/rewind.rs` covers `time` tracks: rewind and replay, clip starts on the remapped clock, eased keys, freezes, seconds text, motion blur during a rewind, the scene document and refusals.

### GSAP

- Page scripts run once at compile time in Boa (`boa_engine` 0.22, vendored with the operand-order fix in `vendor/boa_engine`) against a Rust-owned DOM. `src/gsap/dom.rs` holds the element tree, inline styles, attributes and text; `src/gsap/dom.js` builds the browser globals over it (`document`, elements, `style`, `classList`, `dataset`, `getComputedStyle`, `getBoundingClientRect`, offset sizes, SVG geometry, `matchMedia`, events and timers). The real GSAP library runs unmodified.
- GSAP loads from the page's classic `<script src>`. A CDN GSAP URL resolves to its file name in `CompileOptions.gsap_dir`, else `DIRECTOR_GSAP_DIR`, else the nearest `node_modules/gsap/dist` at or above the source directory, and packed projects bundle the bytes under the URL. A local copy whose major version differs from the URL's fails. Local `src` scripts read through the asset store. Module scripts, other remote scripts and non-JavaScript types fail.
- Layout and computed-style reads during setup compile the current DOM natively and answer from that layout. `Date.now` and `performance.now` return 0, `Math.random` is seeded, `requestAnimationFrame` never fires, and a delayed `setTimeout` or a `setInterval` fails once setup settles. `fetch`, `XMLHttpRequest`, Web Animations and shadow DOM fail. While the timeline plays, a script may add a detached node to the document and remove it before the frame ends, as GSAP's measuring helpers do; a node left in place fails with `scripts left a <tag> in the document`, and any other structure change fails.
- Geometry reads follow browsers. `getBoundingClientRect` maps the layout box through the element's own and every ancestor CSS transform about its origin, the svg `viewBox` with `preserveAspectRatio`, nested svg placement and SVG `transform` attributes. `offsetLeft` and `offsetTop` are untransformed offsets from `offsetParent`, the nearest positioned or transformed ancestor, else the body. An unprobed `position: absolute` or `fixed` box places itself from its inline insets and size. SVG `getCTM`, `getScreenCTM`, `transform.baseVal.getItem` and `viewBox.baseVal` answer from the same matrices.
- `getTotalLength` and `getPointAtLength` measure path, line, polyline, polygon, circle, ellipse and rect geometry with Skia contour measures. SVG content answers `getComputedStyle` from its inline style, then its presentation attribute, then the SVG initial value. GSAP plugins such as `DrawSVGPlugin` load from their CDN file name in the same directory as GSAP.
- After `DOMContentLoaded` and `load`, the compiler seeks every frame (`ceil(duration * fps) + 1` of them): the GSAP root and every timeline in `window.__timelines` move to the frame time, callbacks run, and each frame records the changed inline styles, attributes and text. With `data-motion-blur` above 1 it also seeks the renderer's shutter sample times around each frame (`data-shutter-angle`, at or after 0 s), and every sample records the same way.
- Constant results bake into the HTML. `pointer-events`, `cursor`, `will-change`, `user-select` and `touch-action` drop. `visibility: inherit` reads as `visible`, and autoAlpha's hidden state drops while opacity is 0. Equal `border-*-radius` longhands form one radius. A `transform-origin` GSAP sets once bakes.
- Varying `opacity`, `color`, `background-color`, `width`, `height`, `left`, `top`, `border-radius`, `border-color`, `border-<side>-color`, `border-<side>-width`, `font-size`, `letter-spacing`, `word-spacing`, `font-stretch`, `font-variation-settings`, `line-height`, `padding`, `margin` (and their sides), `transform`, `filter`, `box-shadow`, `text-shadow`, `background-position`, `background-size` and `clip-path` become `director-timeline/1` tracks with one linear key per sample, thinned by swing-door over the real sample times within a per-channel tolerance (px 0.02, percent and degrees 0.01, scale 1e-4, opacity and color 5e-4, line height 1e-3). Shutter samples read sampled values; other sub-frame reads interpolate between keys. Transforms decompose into the component channels (`translate-x`, `translate-y`, `translate-z`, `translate-x-percent`, `translate-y-percent`, `rotate-z`, `rotate-x`, `rotate-y`, `skew-x`, `skew-y`, `scale-x`, `scale-y`). Before GSAP first writes a transform, a cascade transform with no component form shows as GSAP's own decomposition of its matrix. Filters split into the filter channels, `font-variation-settings` into one `font-variation-<axis>` channel per axis tag (an unset axis starts from `font-stretch` for `wdth`, `font-weight` for `wght`, the font size for `opsz`, and 0 for `ital` and `slnt`), shadows, clips and background positions into their list channels, and `border-color`, `padding` and `margin` into their four sides (see Timeline JSON). A `line-height` sample in px divides by that frame's font size. A border width track on a side whose cascaded `border-<side>-style` is absent, `none` or `hidden` drops, since that side draws no border. A sampled filter that repeats a function fails, and so does a clip whose corner count changes or that turns `none` mid-tween. The DOM's computed `box-shadow` lists each shadow as a browser does (color, four px lengths, `inset`), so GSAP pairs a cascade shadow's lengths with the target's. Computed `text-shadow` lists color and three px lengths, `border-color` lists one color when the sides agree, side colors default to `currentColor`, and `background-position` pairs its `-x` and `-y` longhands. Computed `letter-spacing` and `word-spacing` are px or `normal` (sampled as 0), computed `font-stretch` is a percentage, `background-size` defaults to `auto`, `line-height` is px or `normal`, and `padding` and `margin` list one px value when the sides agree. GSAP tweens `letterSpacing` from `normal` to a unitless number as unitless strings, which browsers reject, so those samples fail; a px end value tweens. A background size axis that moves between px, percent and keywords fails.
- Sets hold. Each frame reports the zero-duration tweens (`gsap.set`, `tl.set`) that fired since the frame before, with their start mapped through `startTime` and `timeScale` up to the driving timeline or the GSAP root. A track channel the set's vars name (transform aliases map to their components, `autoAlpha` to opacity, `text` and `textContent` to the text track, `attr` to attributes) keys the new value at that time with `steps(1, end)`, and swing-door thinning runs on each side of the jump. A set under a repeating or reversed parent maps outside its frame and jumps on the frame that first shows it. A text set keys at the set's time. SVG SMIL holds sets too: a jump emits two values at one keyTime, the hold value and then the new one, with keyTimes, `begin` and `dur` in seconds.
- A varying `textContent`, or a write to an element's only text node, becomes a `text` track keyed on every frame whose text changes, so `snap` counters step exactly. The first frame's text becomes the element's own text.
- Varying attributes and styles on SVG content, and a varying `viewBox` on the svg root, become SMIL `<animate director-clock="composition" fill="freeze">` children of the element, and the first frame's value becomes the base. `transform` normalizes to `matrix()` and colors to `rgba()`. Values with one numeric skeleton interpolate linearly between swing-door keys (tolerance 5e-4); other values change on their frames, or at their set's time, with `calcMode="discrete"`. A value that only fills in from unset bakes.
- An animated inline span becomes an atomic box (see Text) that lays out on one unbreakable line. Its `transform`, `width` and `height` tracks drop, matching browsers, which ignore them on inline boxes. Layout reads during setup see the span unpromoted, so its rect is empty until the timeline plays.
- MotionPathPlugin follows path strings, point lists and `#path` targets, and `align`, `alignOrigin` and `autoRotate` measure through the geometry above, so a path inside a scaled viewBox or a transformed wrapper lines up on the page. MorphSVGPlugin morphs `d` into SMIL, and `convertToPath` swaps a shape for a path during setup. Path data `d` values are rewritten with one command per segment and space-separated numbers before the skeleton check, so the end path GSAP writes back interpolates with the morph frames.
- SplitText loads from its CDN file name like other plugins. The DOM implements `Node.normalize`, and an inline box reports an `offsetParent` like the box that holds its text. Split words and chars (`inline-block` divs) place as atomic boxes, and SplitText groups lines from their measured rects.
- Refusals: any other varying property, varying attributes outside SVG, varying SVG text, and a text node beside other children name the element and its values. GSAP outside the composition fails.
- `director-engine html timeline` prints the emitted tracks. `tests/gsap.rs` and `tests/fixtures/gsap` (entrance, loop, stagger) are the phase 5 GSAP gate set: sampled values checked against GSAP 3.14.2, pixels, keyframes, `transformOrigin`, stagger `ease` and `grid`, callbacks, seeded randomness, step-hold sets (between frames, on a frame, delayed on the root, on text, on SVG SMIL), filter channels (blur, grayscale, drop-shadow), box-shadow channels (offset, inset from none, cascade order) and clip-path corners (inset and circle wipes), border color and width channels (and their drop on a styleless side), text-shadow and background-position channels, font size and letter spacing (also through a flex text leaf), font size and color inherited by children (an `em` child scales, a px child keeps its own), line height in px and unitless, word spacing (static and inherited from a tween), variable font axes (static weight, `font-stretch`, and a `font-variation-settings` tween inherited by a child), padding and margin, background-size in px and percent, motion blur sampling GSAP between frames (and one sample once it rests), `@keyframes` winning over GSAP while they run, text tracks, SVG attribute, transform and fill motion, DrawSVG, MotionPath (strings, point lists, `align` through a viewBox and an ancestor transform, `examples/html/motion-path.html`), MorphSVG, helper elements added and removed mid-timeline, inline boxes and spans, inline boxes resizing their line live (span font size, inherited font size, inline-block padding), SplitText lines, words and chars, path geometry, scene export, Boa operand order and refusals. The tests load GSAP from `tools/node_modules/gsap/dist`.
- `tools/parity.mjs` checks the fixtures and `examples/html/gsap-motion.html` against GSAP 3.14.2 in Chromium. Every frame must stay within the default gates; plan 10 records the latest run.

### CSS animation

- Authored `@keyframes` become native animation tracks whose duration, easing, and values stay editable on HTML recompile. Scroll-driven keyframes fail. Page scripts run at compile time and their motion becomes `director-timeline/1` tracks (see GSAP).
- `HtmlElement::local_transform` gives the core motion policy the animated transform about its origin, so keyframed movement counts toward motion scoring. A 3D transform contributes its planar part. `tests/motion_policy.rs` covers a static box, a moving box, and one over the speed limit.
- `HtmlElement::moves_between` tells motion blur whether a shutter moves: its start or end inside the range, an animation that changes a value there, or content that moves at the mapped media time. `HtmlElement::child_time_range` maps the range through its `TimeMap` for its descendants, sampling each overlapping segment so an overshooting ease widens the range. An `Animation` holds outside its interval and through its fills, and inside one iteration moves only across keyframes whose values differ; a range spanning an iteration boundary moves. `tests/motion_blur.rs` checks that a held box paints the sharp frame and an infinite loop stays blurred.
- `animation-direction` accepts `normal`, `reverse`, `alternate`, and `alternate-reverse`. `animation-fill-mode` accepts `none`, `forwards`, `backwards`, and `both`. `steps()` with `jump-none` or `jump-both` fails.

## Work Guidance

- Preserve arbitrary-time seek determinism. Reuse immutable assets and resolve static styles before rendering.
- Keep measured parity and performance claims tied to reproducible commands and artifacts.
- CPU/GPU comparisons must synchronize GPU work through readback, verify the actual backend/encoder and probe every MP4's frame count and audio/video/container duration. GPU rendering and NVENC encoding are separate controls.

- A new CSS longhand needs a `src/property.rs` entry. Port a property group to typed values by matching Lightning CSS `Property` variants in its own `src/style/` module. Painting stages live in `src/element/`. Parallel edits must own separate files or separate match arms.
- HTML pixel tests clear to opaque black, inject Roboto, and set `body{margin:0}`. Treat a pixel as empty when r, g, and b are below 20.
