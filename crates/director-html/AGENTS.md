# Purpose

- Compile HTML/CSS and HyperFrames compositions into Director scenes without browser frame rendering.

## Ownership

- `src/` owns parsing, cascade, style translation, deterministic animation, native element adapters, and captured-scene loading.
- `src/project.rs` owns `director-native-project/1`, editable source and validated element overrides; `src/assets.rs` owns asset recording, deduplicated SHA-256 blobs and temporary media-file leases.
- `tools/` owns optional compile-time browser extraction, Chromium and CPU/GPU parity, real HyperFrames CLI and CPU/GPU export benchmarks, and Hyper CN registry auditing.
- `tests/` owns executable compatibility and pixel regressions.
- `benches/` owns Criterion compile/render workloads.
- `README.md` owns supported features, incompatibilities, commands, and reproducible measured results.

## Local Contracts

- Nested style rules flatten into the same selector list as top-level rules. `&` is replaced with the parent selector. A parent list becomes `:is(...)`. Nested `@media` and `@supports` evaluate at compile time against the composition size. `(orientation: landscape)` is true when width is at least height. `(aspect-ratio)`, `(min-aspect-ratio)`, and `(max-aspect-ratio)` compare width/height to the ratio. Top-level `@media` still fails with `unsupported CSS at-rule`. Unknown media features still fail. `@supports` is true for `display` (`block`, `flex`, `grid`, `inline`, `inline-block`, `none`), `background-clip` (`text`, `border-box`, `padding-box`, `content-box`), `text-overflow` (`ellipsis`, `clip`), `object-fit` (`fill`, `cover`, `contain`, `none`, `scale-down`), `position` (`static`, `relative`, `absolute`), and `overflow` / `overflow-x` / `overflow-y` (`visible`, `hidden`, `clip`). Any other declaration still fails. `(position: fixed)` still fails.
- Depend on `director-core`; do not introduce HTML behavior into Rhai or the core dependency-graph compiler.
- Use upstream HTML, CSS, selector, layout, typography and SVG libraries. Unsupported syntax or rendering behavior must produce diagnostics; compilation fails when errors remain.
- Browser extraction is explicit and compile-time only. Capture layout, style, SVG and media references, never screenshots as native scene content. Captures declare their sample rate and cannot claim continuous animation equivalence.
- Do not treat Hyper CN WebGL/canvas content as supported until a native translation exists. Registry audits must distinguish renderable inputs from diagnosed incompatibilities.
- The smoke extractor forwards a non-none computed `perspective` with its origin, `backface-visibility: hidden`, and SVG-descendant `filter` / `mix-blend-mode`. It copies `text-decoration-line` when every token is `underline`, `overline`, or `line-through`, and copies `mask-mode: luminance`. Other decoration values, other mask modes, `background-blend-mode`, and image-url backgrounds stay refused. `node --test crates/director-html/tools/tools.test.mjs` passed 6 tests on 2026-10-17. That is not a Chrome re-smoke. A canvas with a captured Paper Shader fragment compiles to SKSL and draws in the element content rect. A canvas with no fragment stays refused, as do other WebGL and Three.js runtimes. `fwidth` is a constant screen-width estimate, and `textureGrad` drops explicit derivatives. The 2026-10-15 shader smoke rendered 26/26 original and 26/26 portrait. Carried forward with the 213 blocks that were not re-run, coverage is 239/239. Smoke counts compilation and render. Pixel parity is separate.
- Captured muted video shares one decoder per element id. Sample rect and `object-fit` may change. The active sample seeks that decoder to the composition time. Captured audio is one mixer track per id, including an element the visibility window hides. `data-hidden` sets track volume 0. Audio `loop` loops the track. `data-media-start` drains samples the same way as static HTML. Bytes come from the capture asset map. Unmuted video, an audio playback rate other than 1, iframe, a duplicate media id in one frame, and a media id whose src or timing changes across samples fail. Muted `video loop` seeks with `media_start + elapsed * playback_rate`, then wraps into `[0, duration)`. Duration comes from ffprobe. The capture extractor records `looped` and no longer refuses the attribute. DOM paint stays on the held sample.
- Generated captures, videos, reference checkouts and benchmark reports live under ignored `target/` or user-selected outputs.
- Native adapters must remain semantically Send under the core scene-node contract. Share captured graphs behind `Arc<Mutex<SceneGraph>>`, never `Rc` or an unprotected shared graph.
- Native projects preserve HTML/capture authoring data and compile it on load. Do not serialize HTML adapters through core project I/O, which owns a different node-kind contract.
- Pack every consumed local stylesheet, font, image, audio and video plus required bundled fonts. Frozen project compilation cannot read original files or substitute host files for missing blobs; hash mismatches fail.
- Apply edits by stable authored element ID and validate the complete candidate before acceptance or atomic save. Captures retain sampled timing and fixed geometry; reject edits requiring uncaptured layout/animation.
- Preserve unique authored capture IDs. Anonymous/duplicate IDs receive noncolliding structural paths, stable while sampled topology is stable; expose those paths in inspection and store them in packed captures.
- Keep extracted media files alive through the Director asset-loader lifetime, even when the project or compiler wrapper is dropped.
- Share immutable source and encoded blobs across edit candidates; validation must not clone entire media payloads merely to change an edit map.
- Repeating linear, radial, and conic gradients expand stops across the box and clamp. Color hints expand in sRGB before that tiling. A hint must sit strictly between two stops. A 50% hint stays linear. A hint on the left stop becomes the next color, and a hint on the right stop becomes the previous color. Any other hint inserts nine sRGB stops. Vendor-prefixed gradients fail. An orphan hint fails. A hint that parses and then fails expansion paints nothing.
- Uniform dashed and dotted borders stay one inset stroke. Mixed side styles clip to the border ring and stroke each dashed or dotted side on its midline.
- Parent `perspective` projects descendants only. `transform-style: preserve-3d` depth-sorts direct children by the Z of each child's center after its own local matrix, then z-index, then source order. Positive `translateZ` paints later. A direct child that also preserves 3d contributes its descendants to that same list. Depth sums `view_depth` along the chain. A non-sharing child stays one plane. Crossing `rotateX` planes and a software z-buffer stay out. `flat` keeps z-index order. Other values fail. That Z does not include the parent perspective. `backface-visibility: hidden` skips an element whose own matrix faces away. An absolute `transform-origin` z pivots the local matrix and is included in preserve-3d depth. A percent z still fails. `perspective-origin` z still fails. Perspective distance and `translateZ` are absolute px. The capture extractor copies `transform-style` when the computed value is `preserve-3d`.
- An external stylesheet may set SVG `fill`, `fill-opacity`, `fill-rule`, `color`, `stroke`, `stroke-width`, `stroke-linecap`, `stroke-linejoin`, `stroke-dasharray`, `stroke-dashoffset`, `stroke-opacity`, `stroke-miterlimit`, `opacity`, `transform`, `clip-path`, `clip-rule`, `filter`, and `mix-blend-mode`, plus `marker-start`, `marker-mid`, `marker-end`, and `mask`. `transform` values drop `px` before usvg. `clip-path` and the marker longhands are copied as printed. The `mask` shorthand is stored as `mask-image` and written back as `mask` for usvg. HTML `mask-image` stays on the HTML mask path. External `animation` and its longhands still fail. SVG text, foreignObject, SMIL, scripts, and nested images stay rejected.
- Captured style edits do not accept perspective, transforms, or border-style. Authored HTML recompiles those properties.
- A `url()` or `data:` background is one layer in `background-image` and paints before content. Size accepts `auto`, `cover`, `contain`, and lengths. Repeat accepts `repeat`, `no-repeat`, `repeat-x`, `repeat-y`, `space`, and `round`. The four shader modes map image space onto the canvas. A file URL resolves through the compile `AssetStore`, so `CompileOptions.base_dir` and a frozen project blob apply. A data URI still decodes inline. A gradient shader is sized to `background-origin` and clamped across the border box. The default origin is padding-box, so a transparent border shows the end color. `border-box` sizes the gradient to the border box. Masks stay on the border box. Any number of `url()` layers may share `background-image` with gradients. CSS order paints the first layer on top. A missing file still fails. `background-size`, `background-position`, and `background-repeat` are comma lists aligned with the layers. A shorter list cycles by source index, so one value still applies to every layer. The x and y lists cycle independently. A `none` layer is dropped before that index, so it does not consume a list entry. `none` layers are skipped. `text-decoration` paints `underline`, `overline`, and `line-through` in `currentColor`. Styles are solid, double, dotted, dashed, and wavy. Thickness is `auto`, a length, or a percent of 1em. `from-font` uses the font underline thickness and falls back to auto when that metric is missing or not positive. `text-transform` accepts `none`, `uppercase`, `lowercase`, and `capitalize`. `capitalize` uppercases the first character of each whitespace-separated word and leaves the rest unchanged. `full-width` and `full-size-kana` still fail. `text-shadow` paints one shadow. `none` paints none. A second shadow fails. A non-zero spread fails. `overflow-wrap` and `word-wrap` accept `normal`, `break-word`, and `anywhere`. `word-break` accepts `normal`, `break-word`, and `break-all`. `keep-all` still fails. `anywhere`, `break-word`, and `word-break: break-word` break a token that does not fit. `break-all` also splits a token that overflows the space left on the line. `normal` keeps that token on one line. A token that fits stays whole. Left alignment lays the overflowing line out past the box. Other alignments can still split that line. Soft min-content stays the unwrapped line, so `anywhere` does not shrink to one character. The capture extractor copies both properties. That copy is not a Chrome re-smoke. `text-decoration-color` paints that color. `currentcolor` stays the text color. A dashed underline leaves a gap. `object-position` positions image and video content, including a captured video's shared decoder. The default is 50% 50%. Keyword order can swap axes. One keyword plus a length sets the other axis. `mask-mode: luminance` writes Rec.709 luma into alpha and blends with `DstIn`. `background-origin: content-box` insets the image by the border plus the padding. Percentage padding uses the element width. `space` and `round` paint explicit tiles, including a repeat axis mixed with either one. A product above 4096 tiles is capped. `repeat`, `no-repeat`, `repeat-x`, and `repeat-y` stay on the image shader. Fixed or local attachment and a non-gradient mask image still fail. `background-clip: content-box` clips the background to the content edge. `padding-box` clips to the padding edge. `border-box` still paints the border box. `background-origin` is unchanged. Measured 2026-10-17 by `cargo test -p director-html --release` on the listed filters: lib 101, paint_gaps 22, object_position_css 9, css_nesting 12, css_media 6, gradient_hints 8, depth_sort 7, depth_nested 1, svg_presentation 11, svg_markers 3, background_layers 5, mixed_calc 4, grid_lines 1, project 7, shader 10. media.rs, authoring_slices, and compatibility were not re-run. compatibility stays 23. background_layers and paint_gaps were re-run on 2026-10-18. `cargo test -p director-html --release --test mixed_calc --test gradient_calc` passed mixed_calc 12 and gradient_calc 3 on 2026-10-18. CSS named color `green` is `#008000`.

Homogeneous percents stay percents (`50%` is fraction `0.5`). `convert_length` still passes no percent basis. `length_on` resolves a mixed calc when the caller supplies a finite basis greater than 0. ## Work Guidance

- Preserve arbitrary-time seek determinism. Reuse immutable assets and resolve static styles before rendering.
- Keep measured parity and performance claims tied to reproducible commands and artifacts.
- CPU/GPU comparisons must synchronize GPU work through readback, verify the actual backend/encoder and probe every MP4's frame count and audio/video/container duration. GPU rendering and NVENC encoding are separate controls.
- Exercise real Hyper CN original and portrait registry files. Compilation/render smoke results are separate from measured pixel parity.
