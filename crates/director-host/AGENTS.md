# Purpose

- Own the host session API of plan 10 phase 4: one open project as a revisioned `director_scene::SceneDocument` with patch, outline, diff, inspect, the QA report, frame render and export, plus the editor protocol over it. The CLI, an MCP server and a future Tauri editor link this crate.

## Ownership

- `src/load.rs` owns `Source` (an input path plus HTML compile settings, the Rhai composition and props) and `Loaded`: loading Rhai, HTML, capture JSON, portable native projects and versioned core projects into a live `Director`, and `Loaded::from_compiled` for compiled HTML, captures and native projects.
- `src/script.rs` owns Rhai evaluation with the composition registry (`eval_script`) and movie resolution (`resolve_movie`, `ResolveOpts`).
- `src/session.rs` owns `Session`, `ExportSettings`, the `Outline` types and `import_registry` (core kinds plus `director-html` kinds).
- `src/diff.rs` owns `diff` and the `Diff` types: the structural diff of two sessions' documents and the patch between them.
- `src/editor.rs` owns the editor protocol: `Editor`, `EditorOptions`, `Command`, `Event` and the owner thread that holds the `Session`.
- `src/frames.rs` owns `SharedFrames`, the shared-memory frame ring (file-backed or anonymous), `FrameStamp` and `SharedFrame`.
- `src/qa.rs` owns `Session::qa`, `QaOptions`, `QaWord`, `QaReport`, `QaIssue`, `QaAudio`, the static pass and `sample_times` (the layout sampling grid shared with the CLI `check`). `src/qa/text.rs` owns the painted text checks (plate document, visibility runs, reading time, contrast, cues). `src/qa/mix.rs` owns the mix checks on 10 ms levels (dead stops, voice against bed, voiceless swells).
- `src/patch.rs` owns `PatchOp`, `NodeSelector`, `Patch`, selector resolution and op application.
- `src/error.rs` owns `HostError`, `ErrorCode` (with a JSON schema whose variant docs describe each code to agents) and the JSON error envelope.
- `tests/session.rs` covers open, outline, accepted and rejected patches, conflicts, removal, retiming, frame repaint, inspection, export progress and cancellation on `examples/html/native-motion.html`, plus dependency reload, the cached WAV, native project edits, diffs and QA scores on generated HTML. `tests/qa.rs` covers failing and passing fixtures for reading time, contrast and late cues, with run edges to frame precision; the mix checks have unit fixtures in `src/qa/mix.rs`. `tests/editor.rs` covers seeks into the ring, repaint after patches and source reloads, seek cancellation, a second mapping of the ring file and audio windows.

## Local Contracts

- `Session::open` loads in export mode, exports the live `Director` to a scene document and holds it at revision 0 with the authored names (HTML `id`s) mapped to `NodeRef`s. `Session::from_document` opens a document directly; both require the document to import.
- `patch(base_revision, ops)` requires `base_revision` to equal the current revision (`conflict` otherwise). Ops apply in order to a copy; the copy must deserialize and import before it replaces the document. Any failure rejects the whole patch and keeps the revision. An empty patch keeps the revision. Errors from an op start with `op <index>:`.
- `set` replaces a JSON pointer inside one node record; `/id`, `/parent` and `/children` are fixed. `set_document` replaces a JSON pointer of the document; `/version` and `/nodes` are fixed. `remove` drops a node and its subtree and refuses a subtree holding a clip's scene root or a mask a remaining node uses. Names of removed nodes leave the name table.
- A selector is an authored name string or a `{"index","generation"}` node id. An unknown name or id is `not_found`.
- `render_frame` paints on one `FrameSession` kept warm until the next revision. `inspect` builds the render manifest on a `Director` imported from the current revision, with `revision`, `source_kind`, `sample_rate`, `element_ids` (the authored names), sampled capture elements, missing fonts and audio tracks.
- `use_gpu` (feature `vulkan`) gives the session a GPU context. `render_frame` then paints on a warm `director_render::TargetSession` on that context, and the session stays on the context's thread. `backend` reports `vulkan` or `cpu`.
- `reload` loads the input again as the next revision and drops unsaved project edits. A failure keeps the document and sets `reload_error` until a reload succeeds. `source_changed` compares the modification time and length of the input and its dependency paths with the last load or reload attempt.
- `edit_project` applies `director_html::ElementEdit`s by element id to the native project input and holds the compiled result as the next revision. Edits that do not compile fail with `invalid_patch` and leave the session unchanged. `save_project` writes the edited project atomically.
- `node(selector, path, leaves)` returns a `NodeView` (`id`, `name`, `kind`, `revision`, `path`, `value`) of the record or the value at a JSON pointer inside it, in the addressing `set` takes; a missing pointer is `not_found`. `leaves` adds every settable leaf pointer below `path` outside `/id`, `/parent` and `/children`, with objects and arrays of numbers as one leaf.
- `manifest` returns the render manifest at a time and `audio_mixer` the decoded tracks, both on the `Director` imported from the current revision. `missing_fonts` lists required bundled fonts the system lacks.
- `audio_window(start, duration)` mixes export-frame chunks covering `[start, start + duration)` on the export clock as interleaved float stereo. `start` snaps down to a frame time; `duration` must be in `(0, MAX_AUDIO_WINDOW]` (60 s). Effect tails carry over from the previous mix on the revision.
- `audio_wav` mixes the timeline into one float-stereo WAV in export-sized chunks on the export clock and caches it until the next revision.
- `export` paints the current revision through `director_render::Renderer::export_options` at `ExportSettings::scale` with an optional alpha override, on a CPU pool or on a supplied GPU context. Missing required fonts fail with `missing_font`. A set cancel flag fails with `cancelled` and leaves nothing at the path. A document without audio tracks writes no audio stream. Progress reports encoded frames on the writer thread.
- `diff(before, after)` matches nodes by authored name, then by node id, when kinds agree. It reports document changes outside `/nodes`, added, removed and moved nodes (another parent or sibling order), and node record changes outside `/id`, `/parent` and `/children`, each at the deepest JSON pointer where both sides share the shape, except that an object or array of numbers (a color, a point) changed in more than one field is one change of the whole value. `patchable` holds when no node was added or moved and every match keeps its node id; `patch` (document sets, node sets by name or id, then removals of removed subtree roots) applied to `before` then yields `after`.
- `qa(options)` reports on the current revision: `score` is 100 minus 20 per error and 5 per warning, floored at 0, and `pass` holds with no errors. Layout samples follow `sample_times(duration, every)` (at most 240). errors (20 points each) are missing required fonts, nodes outside the canvas at every layout sample (reported at the topmost such node), clipped mix samples and non-finite audio; warnings (5 points each) are `text`, `caption` or `smart_caption` nodes crossing the canvas edge or inside the `safe_zone` inset for at least one second of samples, the manifest's caption-over-face and subject-out-of-frame detectors on a one-second grid, true peak above -1 dBTP, a silent mix and integrated loudness more than 2 LU from the target; info covers static stretches (painted frames 0.5 s apart with no visible change for 2 s or more) and mixes above 57600000 samples, which skip analysis. Issues merge per kind and node with `start`, `end`, `count`, the authored `name` and a `fix`, sorted errors first. `audio` holds the mix loudness when the timeline has tracks. `qa_with_progress` reports `(done, total)` over the layout samples, the detector grid, the audio and each static or text scan frame without changing the report. A nonpositive or non-finite `every`, a non-finite `loudness_target`, an unknown safe-zone preset or a word without finite `0 <= start <= end` fail with `invalid_argument`.
- Text checks (warnings, one issue per run): a plate copy of the document hides every text glyph (HTML text content and `text` records at opacity 0). Both paint on CPU frame sessions at the static-pass steps, plus the middle of every gate span shorter than a step, and the plate paints only where a text node's gate (HTML `start`, `end` and `hidden` up its chain above any `time_map`, and the clips placing its root) is open. Glyph pixels differ from the plate by more than 8 in a channel and belong to the smallest active text box (manifest bounds) holding them; a node shows from 16 glyph pixels. Runs settle their edges to frame precision only when a check could fire, through a gate boundary or bisection. `reading_time` fires when a run holds under max(1 s, 0.3 s a word) and transcript words overlapping it cover under half its words. `contrast` fires when the 75th percentile WCAG ratio of glyph pixels against the plate, at the scanned frame nearest the run's middle, is under 3:1. `cue_late` fires when a run starts more than 0.2 s after the transcript word (within 3 s, matching the first two words) its text opens with. With text the static pass reads the scan frames.
- Mix checks (warnings) on 10 ms mono RMS levels of a finite, non-silent mix: `dead_stop` when a bed steady within 6 dB over the second before and above -50 dB falls 12 dB or more within 20 ms and stays down 300 ms. With `words`: `voice_bed` over 6 s windows at a 3 s hop that are at least 70% voice (words padded 0.5 s) whose P90 minus P3 spread is under 12 dB, merged; `voiceless_loud` for stretches of 1 s or more outside the padded words whose 400 ms level at P90 passes the voice median by more than 3 dB.
- `Editor::open` opens the session on its own owner thread, runs `EditorOptions::setup` there (a GPU context stays on that thread), creates a `SharedFrames` ring of `FRAME_SLOTS` slots sized for the canvas at its output scale, and sends `Opened` first. `send` gives each `Command` the next generation. A seek older than the newest seek sent reports `Cancelled`; otherwise it paints and publishes a `Frame` naming the ring slot. `Patched` and `Reloaded` repaint the last painted seek unless a newer seek is queued. A changed source reloads before the next command. Failures report `Error` with the command's generation. Dropping the `Editor` finishes queued commands and joins the thread.
- `SharedFrames` layout: a 64-byte header (magic `DRFM`, version 1, slot count, capacity, newest slot plus one, published count) and slots of a 64-byte header (seqlock sequence, generation, revision, time bits, width, height) plus straight-alpha RGBA. One writer publishes; readers in any process copy the newest slot and retry torn reads. `Event::Audio` serializes samples as base64 little-endian `f32` in `samples_f32le`.
- Times must be finite and nonnegative (`invalid_argument`). Every operation fails with a `HostError`; `envelope()` is `{"error":{"code","message"}}` with snake_case codes.

## Work Guidance

- Keep frontends out of the session: new authoring inputs load in `load.rs` and reach the session as a scene document.
- New agent and editor commands call `Session` methods and print `HostError::envelope` on failure.
